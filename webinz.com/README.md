# webinz

Website statis webinz, menggunakan HTML, CSS, dan JavaScript tanpa proses build atau dependensi tambahan.

## GitHub Pages

Semua file situs harus berada langsung di root repository: `index.html`, `portofolio-webinz.html`, `style.css`, `script.js`, dan `webinz-logo-hijau-bulat.png`. Jangan simpan file-file ini di dalam folder `webinz.com/`, karena GitHub Pages tidak akan menemukan `index.html` di alamat utama.

Di Settings > Pages, pilih branch `main` dan folder publikasi `/(root)`. Setelah perubahan dikirim ke branch tersebut, tunggu workflow Pages selesai lalu buka `https://ailynsfk.github.io/webinz/`.
